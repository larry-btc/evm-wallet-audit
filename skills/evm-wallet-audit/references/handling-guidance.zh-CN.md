# 逐项推荐处理方案

[English](handling-guidance.md) · [Skill 入口](../SKILL.zh-CN.md)

帮助用户判断哪些资产值得处理、先做什么以及为什么。盘点旧钱包不代表清仓、追求最高收益或归集到 agent 选定的地址，不提出未经请求的新投资。

## 建议需要依据

- 每项确认资产/仓位给首选下一步：保留作 gas、有条件归集、核实后赎回、等到期、优先检查借贷风险、暂不交互或补查。只有约束相同才合并。
- 包含理由、相关步骤、前置条件、主要风险及可核实的官方入口。链接、风险清单或“自行研究”均不能代替建议。
- 在线查询当前官方规则和必要链上状态。供应商估值只支持参考金额，不证明可赎回、可交易或可领取。离线材料仅给明确条件方案，不编造实时费用/状态。
- 身份、当前仓位及所需条件都有依据才称路径已核实；否则写“先核实 X，满足 Y 后可考虑 Z”。状态条件与退出模拟成功分开。不猜官方域名或深链接。
- 费用估算要有查询时间、网络、操作范围和依据，区分 gas、提前退出损失、协议费、滑点和跨链成本。未知费用保留未知。退出收入不可靠时不计算确定净回收额，也不断言费用高于价值。

## 按资产类型判断

| 类型 | 必须核实的条件 | 推荐方案应回答 |
| --- | --- | --- |
| 原生币/普通代币 | 合约身份、当前余额、可转移性；讨论兑换前还需流动性与可交易性 | 有后续链上操作时保留适量原生币作 gas。归集取决于费用和用户提供的目标地址。报价本身不能支持卖光或转走全部 gas |
| 质押/锁仓/金库份额 | 本金/份额与底层映射、到期、冷却、赎回队列、领取阶段、提前退出损失 | 说明先解除质押、等待、赎回还是领取。未到期应等待或比较有依据的提前退出成本。缺少按钮不证明资金丢失，高 APR 不足以推荐继续 |
| LP，含 V3 仓位 NFT | 具体池/仓位、剩余流动性、底层币、费用/奖励、农场质押、退出限制 | 说明适用顺序，如解除农场质押→移除流动性→领费用/奖励，区分已核实与未知步骤。仅剩费用的仓位单独处理，不把所有 NFT 当收藏品 |
| 借贷/抵押 | 资产、负债、健康度/清算风险、提现对抵押能力的影响、利息及退出限制 | 有证据的紧迫风险优先。说明先偿债、部分退出或等待的条件，不建议先提空抵押物，不假定用户有偿债资金或新借款授权 |
| 待领取/退款/退出队列 | 当前资格/金额、是否已领、到期/领取时间、真实合约及 gas | 建议有条件现在领取、等到已确认时间或先查资格。金额和费用可靠时才判断单独操作是否划算，不重复计入奖励 |
| NFT | 当前持有、是否凭证/LP、可转移性、真实报价/买盘 | 先识别用途。凭证按协议处理，普通收藏品默认保留或另行核价。地板价不承诺收入，不去陌生领取/解锁网站 |
| 无报价/小额/疑似垃圾资产 | 合约、余额、缺失可靠价格、风险标记依据 | 保留数量；无已核实收益路径时补查或暂不交互。小额只影响优先级，不证明无价值或诈骗。不为“清理”授权陌生合约 |
| 停运协议/未完成跨链 | 当前合约状态、官方迁移/退出说明、资金所在侧、完成条件 | 先确认真实资产及现存路径，区分已核实步骤与专项缺口。网页关闭、旧存款或桥消息不证明资金丢失或可取回 |

## 优先级与执行边界

先说当前证据支持的紧迫风险，再处理条件清楚且有实际意义的资产。等待、核价和补查分别列明。没有用户目标和充分证据，不统一建议立即退出。

每项可简写：**首选操作→原因→已核实步骤/官方入口→费用与前提→未知项**。不编造收入、可提金额、解锁时间或交易参数。建议直接显示在聊天中。

查询和建议属于只读工作。本 Skill 不连接钱包、签名或发送资金交易。用户要求执行时，另行授权的流程须在每次签名前确认准确网络、合约/收款方、方法、数量、最低到账/滑点及费用。
